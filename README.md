# GlyphVault

A font manager for macOS. Free to use.

**[Download the latest version](https://github.com/danny3b/GlyphVault-releases/releases/latest)**

## Installation

1. Download the `.dmg` file from the latest release.
2. Open it and drag GlyphVault to Applications.
3. If macOS blocks the first launch, right-click the app and choose Open, or allow it in System Settings → Privacy & Security → Open Anyway.

## Requirements

- macOS 11 or later (Apple Silicon or Intel)
- A free account: you sign in when you first open the app

## Updates

GlyphVault updates itself. Changes in each version are listed under [Releases](https://github.com/danny3b/GlyphVault-releases/releases).

## Privacy

The privacy policy is available in the app: Settings → General → Account.
